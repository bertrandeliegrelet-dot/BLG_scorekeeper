BLG scorekeeper — PWA Android
================================
Version installable comme application web progressive.

IMPORTANT : pour que Chrome propose « Installer l'application », les fichiers doivent être servis depuis une adresse HTTPS (par exemple via un hébergement web). L'ouverture directe du fichier index.html ne suffit généralement pas pour une installation PWA.

Fonctions :
- 2 à 5 joueurs
- 6 points : blanc, bleu, noir, rouge, vert, gris
- Domain : choix de tout point encore manquant
- 5 terrains : point de la couleur correspondante
- Gris : Domain uniquement
- historique
- annulation
- fonctionnement hors connexion après première ouverture
- icône hexagonale BLG
